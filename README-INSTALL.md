# MealFlow V3 — installation guide

## Free hosting with GitHub Pages
1. On a computer, extract the ZIP. Sign into github.com.
2. Create a new **public** repository called `mealflow`.
3. Click **Add file → Upload files**. Upload all extracted files directly to the repository root (including `index.html`, `app.js`, `data.js`, `nutrition.js`, `sw.js`, `manifest.webmanifest`, and both PNG icons). Commit.
4. Open repository **Settings → Pages**. Select **Deploy from a branch**, **main**, **/(root)**, and Save.
5. Once published, open `https://YOUR-USERNAME.github.io/mealflow/` in Chrome on your Pixel 9.
6. Tap Chrome **⋮ → Add to Home screen → Install** (or **Install app**).

## Use
- Plan: choose lunch and dinner individually for all seven days. `Same all week` copies Monday.
- Shop: combined list; More → Package sizes lets you specify actual pack sizes and calculates whole packs to buy.
- Prep: Monday makes 3 portions for Mon–Wed, Thursday makes 4 for Thu–Sun; different recipes are grouped.
- Recipes: edit or add your own recipes.
- More → Nutrition labels: replace estimated values with exact values from your products.
- More → Export backup: save JSON regularly; use Import backup to restore. Browser storage is local, not cloud synced.

Nutrition is estimated until labels are verified, and 2,700 kcal is a target rather than a guaranteed total. Store cooked food safely: refrigerate promptly and freeze portions for later days.
